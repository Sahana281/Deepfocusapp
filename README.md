DeepFocus App 🎯

A simple educational productivity web app to help students be aware and improve on their study habits. 

Features
 - Demo mode available and detailed manual available for user's convenience
 - Customizable timer for focus sessions
 - Distraction button to log distractions with reasons (key to main functionality!)
 - Movable task lists with easy functions
 - Post session productivity ratings
 - Review and Insights section, with summaries of top distractors, top helpers, and small actionable takeaways.
 - 12 earnable badges for a gamification aspect
 - Sound notifications (can be toggled on or off in settings)
 - Timer countdown displayed on the tab in browser even when user is on another tab
 - Secure Firebase email/password login, with data privacy and forgot password functionality

TOOLS:
- Frontend: HTML, CSS, JavaScript
- Firebase authentication and database
- Firebase analytics
- Hosted by CloudFlare 
- LocalStorage

SECURITY:
- User authentication - Firebase
- Data encrypted in transit, and each user can only access their own data
- No third-party tracking (except Firebase Analytics)
- All data stored securely in Firebase Firestore
